Proof Writing

Published

Last modified: 2026-10-29 17:25:41 (PDT)

This page collects general advice on how to write proofs and derivations. The goal of a proof is not just to convince yourself that a result is true; it is to convince a reader, and to show them why it is true. Each principle on this page serves that goal. The symbols for logical entailment are listed under Definitions for proofs below.

1 Definitions for proofs

DefDefinition 1 (Proposition, statement)

Definition 1 (Proposition, statement) A proposition [1], or statement, is a declarative sentence that is either true or false.

ExmExample 1 (Propositions, and a sentence that is not one)

Example 1 (Propositions, and a sentence that is not one)  

  • “\(2 + 3 = 5\)” is a proposition, and it is true.
  • “\(7\) is even” is a proposition, and it is false.
  • “\(x > 2\)” is not a proposition on its own: it is true when \(x = 3\) and false when \(x = 1\), so it has no truth value until \(x\) is given a value.
DefDefinition 2 (Predicate)

Definition 2 (Predicate) A predicate [2] \(P(x)\) is a declarative sentence about a variable \(x\) that becomes a proposition (Definition 1) whenever a value is substituted for \(x\).

ExmExample 2 (A predicate)

Example 2 (A predicate) Let \(P(x)\) be the predicate “\(x > 2\)”, for real numbers \(x\).

  • \(P(3)\) is the proposition “\(3 > 2\)”, which is true.
  • \(P(1)\) is the proposition “\(1 > 2\)”, which is false.
DefDefinition 3 (Logical connective)

Definition 3 (Logical connective) A logical connective [3] builds a new proposition (Definition 1) from one or two propositions \(P\) and \(Q\), with a truth value that depends only on the truth values of \(P\) and \(Q\). These notes use five, each defined next: not, and, or, implies, and if and only if.

DefDefinition 4 (Not)

Definition 4 (Not) The logical connective (Definition 3) not [4] is written \(\neg P\) (“not \(P\)”); it is true when \(P\) is false, and false when \(P\) is true.

ExmExample 3 (Negating a true and a false proposition)

Example 3 (Negating a true and a false proposition) Let \(P\) be “\(5 > 3\)”, which is true, and let \(Q\) be “\(2 > 3\)”, which is false.

  • \(\neg P\), “it is not true that \(5 > 3\)”, is false, because \(P\) is true.
  • \(\neg Q\), “it is not true that \(2 > 3\)”, is true, because \(Q\) is false.
DefDefinition 5 (And)

Definition 5 (And) The logical connective (Definition 3) and is written [5] \(P \land Q\) (“\(P\) and \(Q\)”); it is true when \(P\) and \(Q\) are both true, and false otherwise.

ExmExample 4 (Two propositions joined by “and”)

Example 4 (Two propositions joined by “and”) Let \(P\) be “\(3 < 5\)”, which is true, let \(Q\) be “\(5 < 4\)”, which is false, and let \(R\) be “\(5 < 7\)”, which is true.

  • \(P \land R\) is true, because \(P\) and \(R\) are both true.
  • \(P \land Q\) is false, because \(Q\) is false.
DefDefinition 6 (Or)

Definition 6 (Or) The logical connective (Definition 3) or is written [6] \(P \lor Q\) (“\(P\) or \(Q\)”); it is true when at least one of \(P\) and \(Q\) is true, and false when both are false.

ExmExample 5 (Two propositions joined by “or”)

Example 5 (Two propositions joined by “or”) Let \(P\) be “\(3 < 2\)”, which is false, let \(Q\) be “\(5 < 7\)”, which is true, and let \(R\) be “\(5 < 4\)”, which is false.

  • \(P \lor Q\) is true, because \(Q\) is true.
  • \(P \lor R\) is false, because \(P\) and \(R\) are both false.
DefDefinition 7 (Implies)

Definition 7 (Implies) The logical connective (Definition 3) implies is written [7] \(P \Rightarrow Q\) (“if \(P\), then \(Q\)”, or “\(P\) implies \(Q\)”); it is false when \(P\) is true and \(Q\) is false, and true otherwise.

ExmExample 6 (Implications with a true and a false premise)

Example 6 (Implications with a true and a false premise) Take \(x = 3\).

  • \(x > 2 \Rightarrow x > 1\) is true: the premise \(3 > 2\) is true and the conclusion \(3 > 1\) is true.
  • \(x > 2 \Rightarrow x > 4\) is false: the premise \(3 > 2\) is true, but the conclusion \(3 > 4\) is false.
  • \(x > 5 \Rightarrow x > 4\) is true: the premise \(3 > 5\) is false, so the implication is true whatever the conclusion.
DefDefinition 8 (If and only if)

Definition 8 (If and only if) The logical connective (Definition 3) if and only if is written [8] \(P \Leftrightarrow Q\) (“\(P\) if and only if \(Q\)”); it is true when \(P\) and \(Q\) have the same truth value, and false otherwise.

ExmExample 7 (“If and only if” with equal and different truth values)

Example 7 (“If and only if” with equal and different truth values) Take \(x = 4\).

  • “\(x\) is even \(\Leftrightarrow x > 3\)” is true: \(4\) is even and \(4 > 3\), so both sides are true.
  • “\(x > 3 \Leftrightarrow x > 5\)” is false: \(4 > 3\) is true, but \(4 > 5\) is false.
ExmExample 8 (Truth values of connectives)

Example 8 (Truth values of connectives) Let \(P\) be “\(2 + 3 = 5\)”, which is true, and let \(Q\) be “\(7\) is even”, which is false.

  • \(\neg Q\), “\(7\) is not even”, is true, because \(Q\) is false.
  • \(P \land Q\) is false, because \(Q\) is false.
  • \(P \lor Q\) is true, because \(P\) is true.
  • \(P \Rightarrow Q\) is false, because \(P\) is true and \(Q\) is false.
  • \(Q \Rightarrow P\) is true, because \(Q\) is false.
  • \(P \Leftrightarrow Q\) is false, because \(P\) and \(Q\) have different truth values.
DefDefinition 9 (Truth table)

Definition 9 (Truth table) A truth table [9] for a proposition built from propositions \(P_1, \ldots, P_n\) with logical connectives has one row for each of the \(2^n\) combinations of truth values of \(P_1, \ldots, P_n\), and gives the truth value of the proposition in each row.

ExmExample 9 (A truth table for \(P \Rightarrow Q\))

Example 9 (A truth table for \(P \Rightarrow Q\)) The proposition \(P \Rightarrow Q\) is built from two propositions, so its truth table has \(2^2 = 4\) rows. By the definition of implies, \(P \Rightarrow Q\) is false only in the row where \(P\) is true and \(Q\) is false:

\(P\) \(Q\) \(P \Rightarrow Q\)
T T T
T F F
F T T
F F T
DefDefinition 10 (Logically equivalent)

Definition 10 (Logically equivalent) Two propositions \(A\) and \(B\), each built from some or all of the propositions \(P_1, \ldots, P_n\) with logical connectives, are logically equivalent [10], written \(A \equiv B\), when they have the same truth value in every row of a truth table on \(P_1, \ldots, P_n\).

ExmExample 10 (\(P \Rightarrow Q\) is logically equivalent to \(\neg P \lor Q\))

Example 10 (\(P \Rightarrow Q\) is logically equivalent to \(\neg P \lor Q\)) Adding a column for \(\neg P \lor Q\) to the truth table of Example 9 gives:

\(P\) \(Q\) \(\neg P\) \(\neg P \lor Q\) \(P \Rightarrow Q\)
T T F T T
T F F F F
F T T T T
F F T T T

The last two columns agree in every row, so \((P \Rightarrow Q) \equiv (\neg P \lor Q)\).

LemTheorem 1 (De Morgan’s laws for propositions)

Theorem 1 (De Morgan’s laws for propositions) For any propositions \(P\) and \(Q\) [11]:

\[ \begin{aligned} \neg (P \land Q) &\equiv \neg P \lor \neg Q \\ \neg (P \lor Q) &\equiv \neg P \land \neg Q \end{aligned} \]

ProofProof

Proof. Each side of each law is built from \(P\) and \(Q\), so by Definition 10 it is enough to compare the two sides in each of the four rows of a truth table:

\(P\) \(Q\) \(\neg (P \land Q)\) \(\neg P \lor \neg Q\) \(\neg (P \lor Q)\) \(\neg P \land \neg Q\)
T T F F F F
T F T T F F
F T T T F F
F F T T T T

The third and fourth columns agree in every row, which proves the first law, and the fifth and sixth columns agree in every row, which proves the second.

DefDefinition 11 (Quantifier)

Definition 11 (Quantifier) A quantifier [12] turns a predicate \(P(x)\) (Definition 2) about the elements \(x\) of a set \(S\) into a proposition (Definition 1). There are two, each defined next: the universal quantifier and the existential quantifier.

DefDefinition 12 (Universal quantifier)

Definition 12 (Universal quantifier) The universal quantifier [13] “for all” is a quantifier (Definition 11): \(\forall x \in S, P(x)\) (“for every \(x\) in \(S\), \(P(x)\)”) is true when \(P(x)\) is true for every element \(x\) of \(S\), and false otherwise.

ExmExample 11 (A universally quantified proposition)

Example 11 (A universally quantified proposition) Let \(P(x)\) be the predicate “\(x\) is even”.

  • “\(\forall x \in \mathopen{}\left\{2, 4, 6\right\}\mathclose{}, P(x)\)” is true, because \(2\), \(4\), and \(6\) are all even.
  • “\(\forall x \in \mathopen{}\left\{2, 3, 4\right\}\mathclose{}, P(x)\)” is false, because \(P(3)\) is false.
DefDefinition 13 (Existential quantifier)

Definition 13 (Existential quantifier) The existential quantifier [14] “there exists” is a quantifier (Definition 11): \(\exists x \in S, P(x)\) (“there is an \(x\) in \(S\) such that \(P(x)\)”) is true when \(P(x)\) is true for at least one element \(x\) of \(S\), and false otherwise.

ExmExample 12 (An existentially quantified proposition)

Example 12 (An existentially quantified proposition) Let \(P(x)\) be the predicate “\(x\) is even”.

  • “\(\exists x \in \mathopen{}\left\{1, 2, 3\right\}\mathclose{}, P(x)\)” is true, because \(P(2)\) is true.
  • “\(\exists x \in \mathopen{}\left\{1, 3, 5\right\}\mathclose{}, P(x)\)” is false, because none of \(1\), \(3\), and \(5\) is even.
ExmExample 13 (Quantified propositions)

Example 13 (Quantified propositions) Let \(P(x)\) be the predicate “\(x > 2\)”, for integers \(x\).

  • “\(\exists x \in \mathopen{}\left\{1, 2, 3\right\}\mathclose{}, P(x)\)” is true, because \(P(3)\) is true.
  • “\(\forall x \in \mathopen{}\left\{1, 2, 3\right\}\mathclose{}, P(x)\)” is false, because \(P(1)\) is false.
  • “\(\forall x \in \mathopen{}\left\{3, 4, 5\right\}\mathclose{}, P(x)\)” is true, because \(3 > 2\), \(4 > 2\), and \(5 > 2\) are all true.
DefDefinition 14 (Inequality)

Definition 14 (Inequality) An inequality is a proposition (Definition 1) or a predicate (Definition 2) that compares two expressions \(a\) and \(b\) whose values are real numbers, in one of the forms:

  • \(a < b\) (“\(a\) is less than \(b\)”);
  • \(a \le b\) (“\(a\) is less than or equal to \(b\)”);
  • \(a > b\) (“\(a\) is greater than \(b\)”);
  • \(a \ge b\) (“\(a\) is greater than or equal to \(b\)”).
ExmExample 14 (Inequalities)

Example 14 (Inequalities)  

  • “\(3 < 5\)” is an inequality, and it is true.
  • “\(5 \le 3\)” is an inequality, and it is false.
  • “\(x \ge 2\)” is an inequality and a predicate: it is true when \(x = 2\) and false when \(x = 1\).
  • “\(x = 2\)” is not an inequality: it is an equality.
DefDefinition 15 (Logical entailment, logical consequence, deductive consequence)

Definition 15 (Logical entailment, logical consequence, deductive consequence) Propositions or predicates \(P_1, \ldots, P_n\) (Definition 1, Definition 2) logically entail [15] a proposition or predicate \(Q\) when every choice of values for their variables that makes all of \(P_1, \ldots, P_n\) true also makes \(Q\) true. Then \(Q\) is a logical consequence, or deductive consequence, of \(P_1, \ldots, P_n\).

ExmExample 15 (Entailment, and its failure)

Example 15 (Entailment, and its failure) Let \(x\) be an integer.

  • “\(x = 2\)” entails “\(x^2 = 4\)”: the only value that makes “\(x = 2\)” true is \(x = 2\), and \(2^2 = 4\).
  • “\(x > 3\)” and “\(x < 5\)” together entail “\(x = 4\)”: \(4\) is the only integer greater than \(3\) and less than \(5\).
  • “\(x^2 = 4\)” does not entail “\(x = 2\)”: the value \(x = -2\) makes “\(x^2 = 4\)” true, since \((-2)^2 = 4\), but makes “\(x = 2\)” false.

We can use any of:

  • \(\therefore\) (\therefore in LaTeX),
  • \(\Rightarrow\) (\Rightarrow),
  • \(\models\) (\models)

to denote logical entailment (Definition 15). \(\Rightarrow\) also writes the connective “implies” (Definition 7); \(P\) entails \(Q\) exactly when \(P \Rightarrow Q\) is true for every choice of values for the variables in \(P\) and \(Q\).

Let’s save \(\rightarrow\) (\rightarrow) for convergence results.

DefDefinition 16 (Proof)

Definition 16 (Proof) A proof [16] of a proposition (Definition 1) is a finite list of statements that ends with that proposition, in which each statement is

  • an assumption,
  • a definition,
  • a previously proved result, or
  • a consequence of earlier statements in the list, by one rule of logic or algebra.
ExmExample 16 (The sum of two even integers is even)

Example 16 (The sum of two even integers is even) Let \(a\) and \(b\) be even integers (definition). Then \(a = 2j\) and \(b = 2k\) for some integers \(j\) and \(k\), and

\[ \begin{aligned} a + b &= 2j + 2k && \text{(substitute } a = 2j \text{ and } b = 2k \text{)} \\ &= 2(j + k) && \text{(distributive law)} \end{aligned} \]

The second line uses the distributive law. Since \(j + k\) is an integer, \(a + b\) is even (definition). For example,

\[ \begin{aligned} 4 + 10 &= 2 \cdot 2 + 2 \cdot 5 \\ &= 2 \cdot 7 \\ &= 14. \end{aligned} \]

DefDefinition 17 (Derivation)

Definition 17 (Derivation) A derivation is a proof (Definition 16), or a part of one, written as a chain of expressions, one per line, in which each line is joined to the line before it by \(=\) or by an inequality sign (Definition 14), and carries an annotation that names the reason that step holds: an assumption, a definition, a previously proved result, or a rule of algebra.

ExmExample 17 (A derivation with equalities and inequalities)

Example 17 (A derivation with equalities and inequalities) For every real number \(x\):

\[ \begin{aligned} (x + 1)^2 &= x^2 + 2x + 1 && \text{(square of a sum)} \\ &\ge 2x + 1 && \text{(} x^2 \ge 0 \text{)} \\ &> 2x && \text{(} 1 > 0 \text{)} \end{aligned} \]

The first step uses the square of a sum. The steps are \(=\), \(\ge\), and \(>\), so the derivation shows \((x + 1)^2 > 2x\). For example, with \(x = 3\): \((3 + 1)^2 = 16\), and \(16 > 6 = 2 \cdot 3\).

LemTheorem 2 (What a derivation shows)

Theorem 2 (What a derivation shows) Consider a derivation (Definition 17) with expressions \(E_0, E_1, \ldots, E_n\), where each line \(E_j\) is joined to the line \(E_{j-1}\) before it by \(=\), \(\le\) or \(<\).

  1. If every step is \(=\), then \(E_0 = E_n\).
  2. If every step is \(=\) or \(\le\), then \(E_0 \le E_n\).
  3. If every step is \(=\), \(\le\), or \(<\), and at least one step is \(<\), then \(E_0 < E_n\).

The same holds with \(\ge\) and \(>\) in place of \(\le\) and \(<\).

ProofProof

Proof. First, a fact about two steps in a row. For numbers \(a\), \(b\) and \(c\), if \(a \mathrel{R} b\) and \(b \mathrel{S} c\), where \(R\) and \(S\) are each one of \(=\), \(\le\) and \(<\), then \(a \mathrel{T} c\), where \(T\) is

  • \(<\) if \(R\) or \(S\) is \(<\);
  • otherwise \(\le\) if \(R\) or \(S\) is \(\le\);
  • otherwise \(=\).

This holds in each case:

  • If \(R\) and \(S\) are both \(=\), then \(a = c\) (equalities are transitive).
  • If exactly one of \(R\) and \(S\) is \(=\), replace \(b\) by the equal expression in the other relation (substitution). This gives the other relation between \(a\) and \(c\).
  • If neither is \(=\), then each of \(a \mathrel{R} b\) and \(b \mathrel{S} c\) is \(\le\) or \(<\), and \(\le\) means \(<\) or \(=\) (strict and non-strict inequalities). A case with an \(=\) is covered by the previous bullet, and the remaining case is \(a < b\) and \(b < c\), which gives \(a < c\) because \(<\) is transitive on the real numbers. So two steps that are each \(\le\) or \(<\) give \(<\) if either is \(<\), and otherwise \(\le\).

Now let \(T_j\) be the relation named by the same rule applied to the first \(j\) steps of the chain, with \(T_0\) being \(=\). We show \(E_0 \mathrel{T_j} E_j\) by induction on \(j\). For \(j = 0\), \(E_0 = E_0\). If \(E_0 \mathrel{T_j} E_j\), then the step from \(E_j\) to \(E_{j+1}\) and the fact above give \(E_0 \mathrel{T_{j+1}} E_{j+1}\). At \(j = n\), \(T_n\) is \(=\) when every step is \(=\), which is part 1. It is \(\le\) or \(=\) when every step is \(=\) or \(\le\), and \(=\) implies \(\le\), which is part 2. It is \(<\) when some step is \(<\), which is part 3.

The argument for \(\ge\) and \(>\) is the same with the inequalities reversed.

ExmExample 18 (Checking a derivation line by line)

Example 18 (Checking a derivation line by line) The derivation in Example 17 has the steps \(=\), \(\ge\) and \(>\), so by Theorem 2 it shows \((x + 1)^2 > 2x\). The code evaluates the four lines of that derivation at several values of \(x\), and checks each step and the comparison of the first line with the last.

x <- c(-3, -1, 0, 2, 3)
lines <- data.frame(
  x = x,
  line_0 = (x + 1)^2,
  line_1 = x^2 + 2 * x + 1,
  line_2 = 2 * x + 1,
  line_3 = 2 * x
)
steps <- with(
  lines,
  data.frame(
    x = x,
    step_1_equal = line_0 == line_1,
    step_2_geq = line_1 >= line_2,
    step_3_greater = line_2 > line_3,
    first_greater_than_last = line_0 > line_3
  )
)
lines
steps

At all 5 values of \(x\), the three steps hold in 5, 5 and 5 cases, and the first line exceeds the last in 5 cases, as Theorem 2 says. At \(x = 0\), for example, the first line is 1 and the last is 0.

DefDefinition 18 (Result)

Definition 18 (Result) A result is a proposition (Definition 1) that has a proof (Definition 16). These notes label each result by its role: as a theorem, a lemma, or a corollary, each defined next.

ExmExample 19 (A proposition that is a result, and one that is not)

Example 19 (A proposition that is a result, and one that is not) “\(2 + 3 = 5\)” is a proposition (Definition 1) that has a proof, the computation of \(2 + 3\), so it is a result. “\(7\) is even” is a proposition that is false, so it has no proof and is not a result.

RemarkRemark 1 (“Proposition” as a kind of result)

Remark 1 (“Proposition” as a kind of result). Some sources also call a result of moderate importance a “proposition”. In these notes, “proposition” always means a sentence that is true or false (Definition 1), whether or not it has been proved.

DefDefinition 19 (Theorem)

Definition 19 (Theorem) A theorem [17] is a result (Definition 18) of interest in its own right.

ExmExample 20 (A theorem)

Example 20 (A theorem) “The sum of two even integers is even” is a result: Example 16 proves it. It is of interest in its own right, since it applies whenever two even integers are added, as in \(2 + 4 = 6\), so it is a theorem.

DefDefinition 20 (Lemma)

Definition 20 (Lemma) A lemma [18] is a result (Definition 18) proved mainly as a step in the proof of another result.

ExmExample 21 (A lemma in the proof of a larger result)

Example 21 (A lemma in the proof of a larger result) To show that the sum of four even integers \(a\), \(b\), \(c\), and \(d\) is even, write \(a + b + c + d = (a + b) + (c + d)\). By the result of Example 16, \(a + b\) and \(c + d\) are even, and applying that result again to these two sums shows that their sum is even. Here that result is proved mainly as a step in the proof of another result, so it serves as a lemma. For example, \(2 + 4 + 6 + 8 = (2 + 4) + (6 + 8) = 6 + 14 = 20\), which is even.

DefDefinition 21 (Corollary)

Definition 21 (Corollary) A corollary [19] is a result (Definition 18) that follows from a theorem with little extra work.

ExmExample 22 (A corollary of a result)

Example 22 (A corollary of a result) Example 16 proves the result “the sum of two even integers is even”. A corollary follows with little extra work: the sum of three even integers \(a\), \(b\), and \(c\) is even, because \(a + b + c = (a + b) + c\), \(a + b\) is even by that result, and applying the result again to the even integers \(a + b\) and \(c\) shows that \((a + b) + c\) is even. For example,

\[ \begin{aligned} 2 + 4 + 6 &= (2 + 4) + 6 \\ &= 6 + 6 \\ &= 12, \end{aligned} \]

which is even.

DefDefinition 22 (Counterexample)

Definition 22 (Counterexample) A counterexample [20] to a proposition of the form “for every \(x\) in \(A\), \(P(x)\)”, where \(P(x)\) is a predicate (Definition 2), is an element \(x\) of \(A\) for which \(P(x)\) is false. A single counterexample shows that the proposition is false.

ExmExample 23 (A counterexample)

Example 23 (A counterexample) The proposition “for every integer \(n\), \(n + n > n\)” is false. The integer \(n = 0\) is a counterexample: \(0 + 0 = 0\), and \(0 > 0\) is false. The proposition is true for some integers, such as \(n = 3\), since \(3 + 3 = 6 > 3\), but one counterexample is enough to make it false.

DefDefinition 23 (Converse)

Definition 23 (Converse) The converse [21] of the proposition “if \(P\), then \(Q\)” is the proposition “if \(Q\), then \(P\)”.

ExmExample 24 (A true proposition with a false converse)

Example 24 (A true proposition with a false converse) For an integer \(n\), call \(n\) a multiple of \(4\) if \(n = 4k\) for some integer \(k\).

  • “If \(n\) is a multiple of \(4\), then \(n\) is even” is true:

    \[ \begin{aligned} n &= 4k \\ &= 2 \cdot(2k), \end{aligned} \]

    and \(2k\) is an integer.

  • Its converse, “if \(n\) is even, then \(n\) is a multiple of \(4\)”, is false. The integer \(n = 2\) is a counterexample (Definition 22): \(2\) is even, but \(2 = 4k\) only for \(k = \frac{1}{2}\), which is not an integer.

So a proposition can be true while its converse is false.

DefDefinition 24 (Contrapositive)

Definition 24 (Contrapositive) The contrapositive [22] of the proposition “if \(P\), then \(Q\)” is the proposition “if \(\neg Q\), then \(\neg P\)”.

LemTheorem 3 (A conditional is equivalent to its contrapositive)

Theorem 3 (A conditional is equivalent to its contrapositive) For any propositions \(P\) and \(Q\),

\[ (P \Rightarrow Q) \equiv (\neg Q \Rightarrow \neg P). \]

ProofProof

Proof. By the definition of implies, \(P \Rightarrow Q\) is false exactly when \(P\) is true and \(Q\) is false. By the same definition, \(\neg Q \Rightarrow \neg P\) is false exactly when \(\neg Q\) is true and \(\neg P\) is false, that is, exactly when \(Q\) is false and \(P\) is true. So the two propositions are false in the same row of a truth table and true in the other three, which is Definition 10.

ExmExample 25 (The contrapositive versus the converse)

Example 25 (The contrapositive versus the converse) The proposition “if \(n\) is a multiple of \(4\), then \(n\) is even” from Example 24 has:

  • converse (Definition 23): “if \(n\) is even, then \(n\) is a multiple of \(4\)”, which is false;
  • contrapositive (Definition 24): “if \(n\) is not even, then \(n\) is not a multiple of \(4\)”, which is true, by Theorem 3, because the original proposition is true.
DefDefinition 25 (Sufficient condition)

Definition 25 (Sufficient condition) When the proposition “if \(P\), then \(Q\)” is true, \(P\) is a sufficient condition [23] for \(Q\).

ExmExample 26 (A sufficient condition)

Example 26 (A sufficient condition) For a real number \(x\), “if \(x > 5\), then \(x > 2\)” is true, because a number greater than \(5\) is greater than \(2\). So \(x > 5\) is a sufficient condition for \(x > 2\): knowing that \(x = 6\) satisfies \(x > 5\) is enough to conclude that \(6 > 2\).

DefDefinition 26 (Necessary condition)

Definition 26 (Necessary condition) When the proposition “if \(P\), then \(Q\)” is true, \(Q\) is a necessary condition [23] for \(P\).

ExmExample 27 (A necessary condition)

Example 27 (A necessary condition) For an integer \(n\), “if \(n\) is a multiple of \(6\), then \(n\) is a multiple of \(3\)” is true, because \(6k = 3 \cdot(2k)\) for every integer \(k\). So being a multiple of \(3\) is a necessary condition for being a multiple of \(6\): \(12 = 6 \cdot 2\) is a multiple of \(6\), and it is also a multiple of \(3\), since \(12 = 3 \cdot 4\).

DefDefinition 27 (Necessary and sufficient condition)

Definition 27 (Necessary and sufficient condition) When both “if \(P\), then \(Q\)” and its converse (Definition 23) are true, \(P\) is a necessary and sufficient condition [23] for \(Q\) (Definition 25, Definition 26), written “\(P\) if and only if \(Q\)”.

ExmExample 28 (Necessary but not sufficient)

Example 28 (Necessary but not sufficient) In Example 24, “if \(n\) is a multiple of \(4\), then \(n\) is even” is true, so:

  • being a multiple of \(4\) is a sufficient condition for \(n\) to be even;
  • being even is a necessary condition for \(n\) to be a multiple of \(4\).

Being even is not a sufficient condition for being a multiple of \(4\): \(n = 2\) is even, but not a multiple of \(4\).

DefDefinition 28 (Proof by contradiction)

Definition 28 (Proof by contradiction) A proof by contradiction [24] of a proposition \(P\) assumes that \(P\) is false, and derives from that assumption a proposition that is known to be false.

ExmExample 29 (No integer is both even and odd)

Example 29 (No integer is both even and odd) Suppose, for contradiction, that some integer \(n\) is both even and odd (definition). Then \(n = 2j\) and \(n = 2k + 1\) for some integers \(j\) and \(k\), and

\[ \begin{aligned} 2j &= 2k + 1 && \text{(both equal } n \text{)} \\ 2j - 2k &= 1 && \text{(subtract } 2k \text{ from both sides)} \\ 2(j - k) &= 1 && \text{(distributive law)} \\ j - k &= \tfrac{1}{2} && \text{(divide both sides by } 2 \text{)} \end{aligned} \]

The third line uses the distributive law. But \(j - k\) is an integer, and \(\frac{1}{2}\) is not, so the last line is false. So no integer is both even and odd. For example, \(6 = 2 \cdot 3\) is even, and \(6 = 2k + 1\) would need \(k = 2.5\), which is not an integer.

LemTheorem 4 (A proof by contradiction proves its proposition)

Theorem 4 (A proof by contradiction proves its proposition) Let \(P\) and \(Q\) be propositions (Definition 1). If \(\neg P \Rightarrow Q\) is true and \(Q\) is false, then \(P\) is true.

ProofProof

Proof. By Definition 7, \(\neg P \Rightarrow Q\) is false only when \(\neg P\) is true and \(Q\) is false. Here \(Q\) is false, and \(\neg P \Rightarrow Q\) is true, so \(\neg P\) is not true. Then \(\neg P\) is false. Since \(\neg P\) is true whenever \(P\) is false, \(P\) must be true.

ExmExample 30 (A truth table for a proof by contradiction)

Example 30 (A truth table for a proof by contradiction) There are only four ways to assign truth values to \(P\) and \(Q\). The code lists them, with the truth value of \(\neg P \Rightarrow Q\), and marks the rows where \(\neg P \Rightarrow Q\) is true and \(Q\) is false.

tt <- expand.grid(Q = c(TRUE, FALSE), P = c(TRUE, FALSE))
tt$not_P_implies_Q <- !(!tt$P) | tt$Q
tt$hypotheses_hold <- tt$not_P_implies_Q & !tt$Q
tt

The hypotheses of Theorem 4 hold in 1 of the 4 rows, and in 1 of them \(P\) is true. So whenever the hypotheses hold, \(P\) is true.

2 Don’t skip steps

Show every step of the derivation. Each line should follow from the previous line by a single, identifiable move:

  • applying a definition,
  • substituting a known result, or
  • performing one algebraic operation.

When you skip steps, you force the reader to reconstruct your reasoning, which is exactly the work the proof was supposed to do for them. A step that feels “obvious” while you are writing it is often the step a reader gets stuck on. Phrases like “it can be shown that” or “clearly” usually mark a skipped step; show the step instead.

3 Annotate each step

For each step, note the definition, theorem, or algebraic rule that justifies it. A brief annotation to the right of the line is usually enough. Annotations make the proof checkable, and they teach the reader which tool to reach for next time.

For example, here is a derivation that the hat matrix \(\mathbf{H} = \mathbf{X}({\mathbf{X}}^{\top}\mathbf{X})^{-1}{\mathbf{X}}^{\top}\) is idempotent, \(\mathbf{H}^2 = \mathbf{H}\), with each step annotated:

\[ \begin{aligned} \mathbf{H}^2 &= \mathbf{H}\mathbf{H} && \text{(definition of a matrix power)} \\ &= \mathbf{X}({\mathbf{X}}^{\top}\mathbf{X})^{-1}{\mathbf{X}}^{\top}\,\mathbf{X}({\mathbf{X}}^{\top}\mathbf{X})^{-1}{\mathbf{X}}^{\top} && \text{(definition of } \mathbf{H} \text{)} \\ &= \mathbf{X}({\mathbf{X}}^{\top}\mathbf{X})^{-1}({\mathbf{X}}^{\top}\mathbf{X})({\mathbf{X}}^{\top}\mathbf{X})^{-1}{\mathbf{X}}^{\top} && \text{(regroup; matrix multiplication is associative)} \\ &= \mathbf{X}\,\mathbf{I}_p\,({\mathbf{X}}^{\top}\mathbf{X})^{-1}{\mathbf{X}}^{\top} && \text{(a matrix inverse times the matrix is } \mathbf{I}_p \text{)} \\ &= \mathbf{X}({\mathbf{X}}^{\top}\mathbf{X})^{-1}{\mathbf{X}}^{\top} && \text{(the identity matrix changes nothing)} \\ &= \mathbf{H} && \text{(definition of } \mathbf{H} \text{)} \end{aligned} \]

The Linear Algebra page uses this derivation to show that \(\mathbf{H}\) is a projection matrix. The probability notes derive the variance identity \({\operatorname{Var}\mathopen{}\left(X\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[X^2\right]\mathclose{}} - {\mathopen{}\left({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\right)\mathclose{}}^{2}\) in the same annotated style.

4 Direct proof

DefDefinition 29 (Direct proof)

Definition 29 (Direct proof) A direct proof [25] of a proposition \(Q\) starts from the assumptions that \(Q\) is stated under, if any, and reaches \(Q\) through a chain of steps, each of which applies a definition, a previously proved result, or one rule of logic or algebra to the assumptions or to earlier steps. A direct proof never assumes that \(Q\) is false; compare proof by contradiction, which does.

ExmExample 31 (The square of an odd integer is odd)

Example 31 (The square of an odd integer is odd) Claim: if \(n\) is an odd integer, then \(n^2\) is odd.

Since \(n\) is odd, there is an integer \(k\) with \(n = 2k + 1\). Then

\[ \begin{aligned} n^2 &= (2k + 1)^2 && \text{(substitute } n = 2k + 1 \text{)} \\&= (2k)^2 + 2 \cdot 2k \cdot 1 + 1^2 && \text{(square of a sum)} \\&= 4k^2 + 4k + 1 && \text{(arithmetic)} \\&= 2(2k^2 + 2k) + 1 && \text{(distributive law, read from right to left)} \end{aligned} \]

and \(2k^2 + 2k\) is an integer, because adding or multiplying integers gives an integer. So \(n^2 = 2 \cdot(\text{an integer}) + 1\), which is the definition of odd. For example,

\[ \begin{aligned} n &= 7 \\ &= 2 \cdot 3 + 1 \end{aligned} \]

gives

\[ \begin{aligned} n^2 &= 49 \\ &= 2 \cdot 24 + 1, \end{aligned} \]

and \(2 \cdot 3^2 + 2 \cdot 3 = 24\).

The proof above that the sum of two even integers is even is also a direct proof.

5 Proof by contrapositive

DefDefinition 30 (Proof by contrapositive)

Definition 30 (Proof by contrapositive) A proof by contrapositive [22] of a proposition “if \(P\), then \(Q\)” is a direct proof of its contrapositive, “if \(\neg Q\), then \(\neg P\)”: it assumes that \(Q\) is false and reaches the conclusion that \(P\) is false. By Theorem 3, proving the contrapositive proves the original proposition.

ExmExample 32 (If \(x^2 + 3x < 0\), then \(x < 0\))

Example 32 (If \(x^2 + 3x < 0\), then \(x < 0\)) Claim: for every real number \(x\), if \(x^2 + 3x < 0\), then \(x < 0\).

A direct proof would have to start from the inequality \(x^2 + 3x < 0\), which says little about \(x\) on its own. The contrapositive (Definition 24) is “if \(x \ge 0\), then \(x^2 + 3x \ge 0\)”, and its assumption is easier to use.

Suppose \(x \ge 0\). Then \(x^2 = x \cdot x \ge 0\), because a product of two nonnegative numbers is nonnegative, and \(3x \ge 0\), because \(3 > 0\) and \(x \ge 0\). So

\[ \begin{aligned} x^2 + 3x &\ge 0 + 0 && \text{(add the inequalities } x^2 \ge 0 \text{ and } 3x \ge 0 \text{)} \\&= 0. && \text{(arithmetic)} \end{aligned} \]

That proves the contrapositive, so by Theorem 3 the claim holds. For example, \(x = -1\) gives \(x^2 + 3x = 1 - 3 = -2 < 0\), and indeed \(x < 0\).

6 Proof by cases

DefDefinition 31 (Proof by cases, proof by exhaustion)

Definition 31 (Proof by cases, proof by exhaustion) A proof by cases [26], also called a proof by exhaustion, of a proposition \(Q\) lists propositions \(C_1, \ldots, C_k\), the cases, shows that at least one of them is true, and proves \(C_i \Rightarrow Q\) for each \(i\).

ExmExample 33 (The square of a real number is nonnegative)

Example 33 (The square of a real number is nonnegative) Claim: for every real number \(x\), \(x^2 \ge 0\).

Every real number \(x\) satisfies \(x \ge 0\) or \(x < 0\), so these two cases cover every \(x\).

Case 1: \(x \ge 0\). Then \(x^2 = x \cdot x\) is a product of two nonnegative numbers, so \(x^2 \ge 0\).

Case 2: \(x < 0\). Then \(-x > 0\), and

\[ \begin{aligned} x^2 &= x \cdot x && \text{(definition of } x^2 \text{)} \\&= (-x) \cdot(-x) && \text{(the two minus signs cancel)} \end{aligned} \]

is a product of two positive numbers, so \(x^2 > 0\), and in particular \(x^2 \ge 0\).

The claim holds in both cases, so it holds for every real number \(x\).

7 Follow the golden rule

In general, follow the golden rule: treat your readers the way you want to be treated as a reader.

When you read someone else’s proof, you want to be able to follow every step without guessing, to know which result is being used at each line, and to never be left wondering where a quantity came from. Write your own proofs to meet that same standard.

8 Proof by induction

Many proofs in these notes show that a statement holds for every natural number \(n\), or for every integer \(n\) from some starting value on. Checking the statement one \(n\) at a time would never finish; induction proves it for all of them with two arguments.

DefDefinition 32 (Proof by induction)

Definition 32 (Proof by induction) Let \(n_0\) be an integer, and let \(P(n)\) be a predicate about the integers \(n \ge n_0\). A proof by induction [27] on \(n\) shows that \(P(n)\) holds for every integer \(n \ge n_0\) by showing two things:

  1. Base case: \(P(n_0)\) holds.
  2. Inductive step: for every integer \(n > n_0\), if \(P(n - 1)\) holds, then \(P(n)\) holds.

In the inductive step, the assumption that \(P(n - 1)\) holds is called the induction hypothesis.

RemarkRemark 2 (Why the two steps suffice)

Remark 2 (Why the two steps suffice). The base case gives \(P(n_0)\). The inductive step with \(n = n_0 + 1\) then gives \(P(n_0 + 1)\), with \(n = n_0 + 2\) it gives \(P(n_0 + 2)\), and so on: each integer \(n \ge n_0\) is reached after \(n - n_0\) uses of the inductive step.

When \(P(n)\) is needed only for \(n_0 \le n \le r\), it is enough to show the inductive step for \(n_0 < n \le r\); the same chain then stops at \(P(r)\).

The following example uses summation notation.

ExmExample 34 (Sum of the first \(n\) natural numbers)

Example 34 (Sum of the first \(n\) natural numbers) For every \(n \in \mathbb{N}\),

\[ \sum_{i=1}^ni = \frac{n(n+1)}{2}. \]

For example, with \(n = 3\), \(1 + 2 + 3 = 6\) and \(\frac{3 \cdot 4}{2} = 6\). To prove the equation for every \(n\), let \(P(n)\) be the equation and use Definition 32 with \(n_0 = 1\).

Base case, \(n = 1\). The sum has one term:

\[ \begin{aligned} \sum_{i=1}^{1} i &= 1 && \text{(definition of a sum)} \end{aligned} \]

and the right side is

\[ \begin{aligned} \frac{1\,(1+1)}{2} &= \frac{1 \cdot 2}{2} && \text{(} 1 + 1 = 2 \text{)} \\ &= \frac{2}{2} && \text{(} 1 \cdot 2 = 2 \text{)} \\ &= 1. && \text{(} \tfrac{2}{2} = 1 \text{)} \end{aligned} \]

So \(P(1)\) holds.

Inductive step. Let \(n \ge 2\), and suppose \(P(n - 1)\) holds:

\[ \sum_{i=1}^{n-1} i = \frac{(n-1)\,\mathopen{}\left((n-1)+1\right)\mathclose{}}{2}. \]

Then

\[ \begin{aligned} \sum_{i=1}^ni &= 1 + 2 + \cdots + (n-1) + n && \text{(definition of a sum)} \\ &= \mathopen{}\left(1 + 2 + \cdots + (n-1)\right)\mathclose{} + n && \text{(associative law)} \\ &= \sum_{i=1}^{n-1} i + n && \text{(definition of a sum)} \\ &= \frac{(n-1)\,\mathopen{}\left((n-1)+1\right)\mathclose{}}{2} + n && \text{(induction hypothesis)} \\ &= \frac{(n-1)\,n}{2} + n && \text{(} (n-1) + 1 = n \text{)} \\ &= \frac{(n-1)\,n}{2} + \frac{2n}{2} && \text{(} n = \tfrac{2n}{2} \text{)} \\ &= \frac{(n-1)\,n + 2n}{2} && \text{(common denominator)} \\ &= \frac{\mathopen{}\left((n-1) + 2\right)\mathclose{}\,n}{2} && \text{(distributive law)} \\ &= \frac{(n+1)\,n}{2} && \text{(} (n-1) + 2 = n + 1 \text{)} \\ &= \frac{n(n+1)}{2}, && \text{(commutative law)} \end{aligned} \]

which is \(P(n)\). By Definition 32, the equation holds for every \(n \in \mathbb{N}\).

9 Formal logic

DefDefinition 33 (Propositional logic)

Definition 33 (Propositional logic) Propositional logic [28] is the study of logical entailment among propositions built from basic propositions \(P, Q, R, \ldots\) using only the logical connectives. Whether such propositions entail one another depends only on the truth values of the basic propositions, not on what the basic propositions say.

ExmExample 35 (\(P\) and \(P \Rightarrow Q\) entail \(Q\))

Example 35 (\(P\) and \(P \Rightarrow Q\) entail \(Q\)) Suppose \(P\) is true and \(P \Rightarrow Q\) is true. If \(Q\) were false, then \(P \Rightarrow Q\) would have a true \(P\) and a false \(Q\), so \(P \Rightarrow Q\) would be false, which contradicts the assumption. So \(Q\) is true. This holds whatever \(P\) and \(Q\) say, so \(P\) and \(P \Rightarrow Q\) logically entail \(Q\).

DefDefinition 34 (First-order logic)

Definition 34 (First-order logic) First-order logic [29] extends propositional logic (Definition 33) by also allowing:

  • variables \(x, y, \ldots\) that stand for elements of a set;
  • predicates of one or more of those variables, such as \(P(x)\) or \(x < y\);
  • functions of them, such as \(x + y\);
  • equality between them;
  • quantifiers \(\forall\) and \(\exists\) over them.
ExmExample 36 (From “for all” to one element)

Example 36 (From “for all” to one element) Let \(P(x)\) be a predicate about the elements of a set \(S\), and let \(a \in S\). The propositions \(\forall x \in S, P(x)\) and \(a \in S\) logically entail \(P(a)\): if \(P(x)\) is true for every element \(x\) of \(S\), then it is true for the element \(a\). For example, \(\forall x \in \mathbb{Z}, x^2 \ge 0\) entails \(3^2 \ge 0\). Propositional logic alone cannot express this entailment, because it has no way to refer to the elements of \(S\).

DefDefinition 35 (Formal proof)

Definition 35 (Formal proof) A formal proof [30] is a proof written in propositional logic (Definition 33) or first-order logic (Definition 34) in which each step is an assumption or follows from earlier steps by one rule taken from a fixed list of allowed rules, so that checking the proof needs no understanding of what its propositions say.

ExmExample 37 (A three-step formal proof)

Example 37 (A three-step formal proof) Suppose the allowed rules include “from \(P\) and \(P \Rightarrow Q\), conclude \(Q\)”. Then this is a formal proof of \(Q\) from the assumptions \(P\) and \(P \Rightarrow Q\):

  1. \(P\) (assumption)
  2. \(P \Rightarrow Q\) (assumption)
  3. \(Q\) (from steps 1 and 2, by the rule above)
