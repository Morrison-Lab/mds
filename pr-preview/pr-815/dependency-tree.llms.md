# How to read the tree

Every definition and [theorem](https://morrison-lab.github.io/mcs/proof-writing.html#def-theorem) in these notes is one box, colored by kind. A box sits below each definition and theorem it uses, so the ones that use no others are at the top. Hover over a box to see its name, and click it to open its page.

# With the prerequisites from math for computer science

These notes build on the [math for computer science notes](https://morrison-lab.github.io/mcs/dependency-tree.html), whose Math Reference pages define [sets](https://morrison-lab.github.io/mcs/sets.html#def-set), [functions](https://morrison-lab.github.io/mcs/functions.html#def-function), numbers and proofs. This tree joins both sets of notes: a box sits below each definition and [theorem](https://morrison-lab.github.io/mcs/proof-writing.html#def-theorem) it uses, in either one, and hovering over a box also shows which notes it is in.
